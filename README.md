**Math Explorer** is a comprehensive monorepo dedicated to implementing advanced mathematical models, physics simulations, and AI algorithms from first principles in Rust.

From **Quantum Mechanics** to **Chaos Theory**, and **Transformers** to **Epidemiology**, this project bridges the gap between theoretical equations and executable code.

## 🚀 Quick Start

**1. Clone and Enter**
```bash
git clone https://github.com/your-repo/math-explorer.git
cd math-explorer
```

**2. Run the Test Suite**
Verify that all mathematical models are behaving correctly:
```bash
cd math_explorer
cargo test
```

**3. Explore the Code**
The core logic resides in the `math_explorer` crate.
👉 **[Read the Crate Documentation](./math_explorer/README.md)** for detailed module guides and examples.

## 📂 Project Structure

| Directory | Description |
|-----------|-------------|
| **[`math_explorer/`](./math_explorer/)** | The Rust source code. Contains all modules (`physics`, `ai`, `applied`, etc.). |
| **[`papers/`](./papers/)** | LaTeX source for accompanying academic papers and theoretical derivations. |

## 🛠️ Key Features

*   **Physics**: Lorenz Systems, MRI Bloch Equations, Fluid Dynamics.
*   **AI**: Transformers (Attention/Self-Attention), Gaussian Splatting, NeRF-Diffusion.
*   **Applied Math**: Clinical Trials Stats, Game Theory, and the *Satirical Favoritism Model*.
*   **Biology**: Neuroscience (Hodgkin-Huxley), Morphogenesis.
