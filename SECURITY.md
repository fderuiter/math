## Reporting a Vulnerability

We take the security of Math Explorer seriously. If you believe you have found a security vulnerability in this project, please report it to us as described below.

**Do not report security vulnerabilities through public GitHub issues.**

### Procedure

1.  Please report the vulnerability by creating a [Security Advisory](https://github.com/fderuiter/math-explorer/security/advisories/new) or emailing the maintainers directly.
2.  You should receive a response within 48 hours.
3.  We will work with you to understand the scope and impact of the issue.
4.  Once resolved, we will publish a security advisory and credit you for the discovery (if desired).

Thank you for helping keep Math Explorer safe!
