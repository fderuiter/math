# Math Explorer Examples Index

This directory contains runnable, copy-pasteable examples for the Math Explorer library.

## Usage

Run any example using Cargo:
`cargo run --release --package math_explorer --example <example_name>`

## Domain Catalog

### 🤖 AI
- `transformer_demo`: Transformer Encoder initialization and forward pass.
- `transformer_simple`: Basic transformer attention mechanism test.

### 🧮 Applied
- `battery_degradation_demo`: Li-ion battery health modeling.
- `favoritism_demo`: Satirical model determining the favorite child.
- `grpo_demo`: Group Relative Policy Optimization.
- `isosurface_torus`: Marching Cubes algorithm for 3D meshes.
- `mmwave_setup`: mmWave Radiotherapy dose calculations.

### 🧬 Biology
- `hodgkin_huxley_demo`: Simulating an excitable neuron's membrane potential.
- `bench_morphogenesis`: Turing pattern generation.
- `bench_evolution`: Evolutionary replicator dynamics.

### 🌍 Climate
- `cera_demo`: Climate-invariant Encoding Representation Alignment.

### 🔬 Physics
- `hello_world`: Quantum Mechanics Clebsch-Gordan calculation.
- `lorenz_chaos`: Lorenz Attractor and Lyapunov exponents.
- `bench_lbm_custom`: Lattice Boltzmann Method for fluid dynamics.
- `bench_ising_custom`: Ising model phase transitions.

### 📐 Pure Math
- `algebra_demo`: Finite Fields and polynomial arithmetic.
- `tensor_demo`: Computing Christoffel symbols for manifolds.
- `glicko2_demo`: Esports rating system simulation.
- `markov_demo`: Markov Chain transition matrices.
- `statistics_demo`: Advanced statistical distribution tests.

For more details, see the inline documentation within each `.rs` file.
